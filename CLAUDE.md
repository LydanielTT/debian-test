# Commit convention

Use [Conventional Commits](https://www.conventionalcommits.org/): `<type>(<optional-scope>): <subject>`.

- **Types:** `feat`, `fix`, `chore`, `docs`, `refactor`, `perf`, `test`, `build`, `ci`.
- Subject: imperative mood, lowercase, no trailing period, ≤ ~72 chars.
- Add a body explaining the *why* when the change isn't self-evident.
- Agent-authored commits end with the trailer:

  ```
  Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>
  ```
